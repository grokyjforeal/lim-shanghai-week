# Shanghai, 22 to 28 October 2026

The Lim family week, as a small site. Xujiahui is the hotel. Friday is Hangzhou's canal. Sunday is the new museum on Jinji Lake. Saturday is Chee Onn's birthday on the Bund.

The research notes, with sources, are in [ITINERARY.md](ITINERARY.md). Confirmation numbers were not included, so the site does not invent them.
